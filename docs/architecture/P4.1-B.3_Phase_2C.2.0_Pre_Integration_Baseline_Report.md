في الأسطر 35-41 من [schedule_weekly_prayers_usecase.dart](file:///c:/Users/shady%20atef/Documents/projects/hafiz_al_ahd/lib/features/notifications/domain/usecases/schedule_weekly_prayers_usecase.dart#L35-L41):

ثم في حلقة الصلوات:
```dart

      if (adhanStyle == 'alarm') { ... }
      else if (adhanStyle == 'notification') { ... }
```

**الهدف القادم في 2C.2.3:** استبدال قراءة `adhanStyle` بقراءة `final configs = await prayerAlarmConfigRepository.getConfigs();` في بداية الجلسة مرة واحدة فقط، والتحقق الصارم من اكتمال الصلوات الخمس والانسحاب الآمن المبكر (Fail-Safe Early Exit) عند أي فشل قبل أي scheduling side-effect.
