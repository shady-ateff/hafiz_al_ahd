## 3. عقد التحويل النطاقي المستقل (The Mapping Contract)

لكل صلاة مفروضة (`fajr, dhuhr, asr, maghrib, isha`)، يتم تحويل إعداد `PrayerAlarmConfig` إلى قرار جدولة مستقل (`PrayerAlertDecision`):

```
PrayerAlarmType.alarm        ===> PrayerAlertDecision.alarm        (جدولة منبه كامل الشاشة)
PrayerAlarmType.notification ===> PrayerAlertDecision.notification (جدولة إشعار صوتي بسيط)
PrayerAlarmType.off          ===> PrayerAlertDecision.none         (عدم جدولة أي تنبيه للصلاة)
```

### القواعد المعمارية الثابتة (Mapping Invariants):
1. **استقلال مطلق:** قرار كل صلاة مستقل 100% عن باقي الصلوات الخمس.
2. **فردية القرار:** لا يمكن لأي صلاة أن تنتج `alarm` و `notification` معاً.
3. **انعدام الأثر الجانبي لـ `off`:** ضبط أي صلاة على `off` يعطل تنبيه الأذان لتلك الصلاة فقط، ولا يؤثر إطلاقاً على الإقامة أو الأذكار.
4. **صفر قراءات إضافية:** لا يتم استدعاء أي قراءة من التخزين أثناء التحويل؛ يعتمد التحويل على الخريطة الموثقة والمحقونة في الذاكرة.
5. **عدم وجود Fallback:** لا يتم الرجوع أبداً إلى `adhanStyle` في منطق التحويل الجديد.

## 4. استقلال الأحداث الإضافية (Auxiliary Events Orthogonality)

تم التأكد من الفصل التام بين الأحداث الثلاثة:
1. **Prayer Alert:** يخضع مباشرة وبشكل حصري لـ `PrayerAlarmConfig.alarmType`.
2. **Iqama Alert:** يخضع حصرياً لـ `isIqamaEnabled && iqamaDelay > 0`، ولا يتأثر إطلاقاً بكون الصلاة `alarm` أو `notification` أو `off`.
3. **Azkar Reminders:** تخضع حصرياً لـ `isAzkarReminderEnabled`:
   - أذكار ما بعد الصلاة: مستمرة لجميع الصلوات بغض النظر عن إعداد تنبيه الأذان.
   - أذكار الصباح: مرتبطة حصرياً بصلاة الفجر (`fajr + 30m`) وتظل مجدولة حتى لو كان الفجر `off`.
   - أذكار المساء: مرتبطة حصرياً بصلاة العصر (`asr + 30m`) وتظل مجدولة حتى لو كان العصر `off`.

## 6. التصميم المقترح (Proposed Lightweight Domain Design)

تجنباً لأي تعقيد معماري إضافي (Over-engineering) والتزاماً بشرط **STOP GATE 2C.2.4.4**:
- لا حاجة لإنشاء Framework جديد أو Use Case وسيط أو استخدام Service Locator.
- التصميم المقترح يضيف تعريفين نقيين وبسيطين (Pure Domain Enum & Extension) في:
  [`lib/features/notifications/domain/entities/prayer_scheduling_decision.dart`](file:///c:/Users/shady%20atef/Documents/projects/hafiz_al_ahd/lib/features/notifications/domain/entities/prayer_scheduling_decision.dart):

```dart
/// Represents the independent scheduling decision for a prayer alert.
enum PrayerAlertDecision {
  alarm,
  notification,
  none;

  /// Pure mapping function from PrayerAlarmConfig to PrayerAlertDecision.
  static PrayerAlertDecision fromConfig(PrayerAlarmConfig config) {
    switch (config.alarmType) {
      case PrayerAlarmType.alarm:
        return PrayerAlertDecision.alarm;
      case PrayerAlarmType.notification:
        return PrayerAlertDecision.notification;
      case PrayerAlarmType.off:
        return PrayerAlertDecision.none;
    }
  }

  /// Evaluates the desired state transition from previous to next configuration.
  static PrayerAlertDecision evaluateTransition({
    required PrayerAlarmType? previous,
    required PrayerAlarmType next,
  }) {
    // The desired state is always deterministically driven by the next configuration
    switch (next) {
      case PrayerAlarmType.alarm:
        return PrayerAlertDecision.alarm;
      case PrayerAlarmType.notification:
        return PrayerAlertDecision.notification;
      case PrayerAlarmType.off:
        return PrayerAlertDecision.none;
    }
  }
}

extension PrayerAlarmConfigDecisionX on PrayerAlarmConfig {
  PrayerAlertDecision get decision => PrayerAlertDecision.fromConfig(this);
}
```
